# Tiny Rugby Simulator (TRS) — CLAUDE.md

Personal project (Rocky). A retro rugby game for phones: club careers, a World Cup, set plays. Not Harrows work: never use the Harrows git identity, repos or accounts here.

**Path:** `C:/Users/rockyj/try-time` · **Stack:** Vite + TypeScript, plain Canvas 2D, Vitest. No server, no game engine. Mobile only (landscape, two thumbs); the developer portal is the one desktop thing.

**Status (2026-11-23):** playable end to end in a phone browser over office Wi-Fi. The whole game was rebuilt on 2026-11-23 from a run of written briefs Rocky pasted in (controls, V4, developer portal, set plays in two parts, V5 and two V5 addenda), then V6, V7, V8 and V9 the same day. All of V9 is built and passing its tests; none of it has been played by hand yet. Not wrapped as a native app, not hosted. **Nothing has ever been committed to git**; the pre-rebuild source is at `C:/Users/rockyj/try-time-backup-2026-11-23`.

Rocky playtests on his phone and sends long briefs, often while work is still landing (the dev server hot-reloads). Briefs are written elsewhere and sometimes describe things the build never had (a controlled defender, for instance: the opposition's possessions are a text ticker, there is no playable defence). Treat each brief as the target; where a later one contradicts an earlier one, the later wins.

## Commands
- `npx vite --host` runs the dev server so a phone on the same Wi-Fi can open it (`npm run dev -- --host` loses the flag under PowerShell).
- `npm test` · `npm run build` (type-check + production build)
- `SHOTS=<folder> npx vitest run tests/shots.test.ts` renders screens to PNG with a real headless canvas (`@napi-rs/canvas`) and the game's own fonts, so it matches a phone. This is the only way to see the game from a coding session: headless Chrome hangs on this PC and DevTools is blocked. `SHOT_W=1560` for a phone shape, `SHOT_NAMES=title,squad,ready,tackle,...` (names in `src/demo.ts`), `SHOT_THEME=1` for another colour theme. `node tools/zoom.mjs in.png out.png x y w h` blows up part of a shot to check sprites.
- `/?demo=NAME` on the dev server jumps to a screen.
- `npx vitest run tests/match.test.ts --silent=false` prints bot match scores: the balance check.

## Design rules
- Shapes and sprites are `Gfx.rect` on a 320x180 logical screen. Text is real type via `Gfx.label` (canvas `fillText`); the 3x5 pixel font (`Gfx.pix`) is only for numbers painted on the pitch. In a bare test harness with no `fillText`, labels fall back to the pixel font.
- Fonts ship in `public/fonts` (Alfa Slab One, Inter, Chakra Petch; all open licence, licences alongside).
- Colours and fonts are themes in `src/theme.ts`; code reads `C.gold`, `C.ink` etc. Never hard-code an interface colour. Team kits stay separate from the interface palette.
- Game rules live in pure classes with a seeded `Rng` (`src/match`, `src/career`); screens in `src/ui` only draw and forward input.
- **Nobody teleports.** Between a restart and a score or turnover, players only ever move by running. `tests/flow.test.ts` enforces it. Formation resets are allowed at kick-offs and when a scrum or lineout is first formed, not after it.
- Sentence case for anything read; capitals only in short match banners.
- **Real team and competition names are in as development placeholders** at Rocky's request (V5), all in `src/data/teams.ts`. They are other people's trademarks: they need a licence or replacing before the game is sold. No logos or official artwork anywhere. Player names are generated.

## Layout
- `src/config.ts` every tunable number (`TUNE_DEFS`, read as `T.runSpeed`), the set-play types, and the developer portal's stored state. `src/tuned.json` holds whatever the portal last published; it overrides the defaults everywhere, including the built app.
- `src/theme.ts` palettes and fonts · `src/plays.ts` the playbook, the sample play, the premium flag · `src/scenarios.ts` practice situations
- `src/engine` loop, input events, renderer, sound effects
- `src/match/attack.ts` one continuous passage of play (you attack left to right; x 0..100 m, y 0..40 m): running, passing, kicking, tackles, rucks, and scrums and lineouts once formed
- `src/match/match.ts` match flow around it: kick-offs, ruck outcomes, penalties, kicks for touch, goal kicks, clock, scoring
- `src/match/oppsim.ts` the opposition's possessions, simulated as a text ticker
- `src/career` players, teams, competitions, season flow, off-season, job offers
- `src/ui` screens: `menus.ts` (title, the list of careers, competition and team select, the career frame, My Career, Match Centre, Fixtures & Results, facilities, the credits card), `market.ts` (Open Market and a market player's profile), `kits.ts` (home and away jerseys), `squad.ts`, `training.ts` (the Training Ground), `matchscene.ts`
- `dev.html` + `src/dev/` the developer portal · `tests/bot.ts` a scripted player used to play whole matches in tests

## On the pitch
- **Left thumb runs:** touch to run, drag up/down to move across (sustained drag keeps going; a swipe that is let go carries him on across, `CARRY` in matchscene.ts and `shift()` in the engine, V8), a fast flick is a sidestep, a fast forward swipe within 3 m of the line is a dive. **Right thumb is the ball:** pull back and let go, catapult style. The dotted line is exactly where the ball goes. No buttons, no joystick; the runner always runs forward.
- **Passing is a throw to a point**, never a pick-a-teammate pass. Whoever reaches the ball takes it; a defender in its path may intercept; a ball nobody reaches goes loose and is a race. **A long pass is thrown high** (`passArc`, `HEAD`): it clears the men in between, ours and theirs, and can only be caught where it comes down, which is how a winger is picked out. The man best placed to reach it (`receiver()`, re-chosen every frame) sets off at once, forwards or back, timing his run and never standing to wait.
- **Aiming up the field is a kick.** Four kinds from one physics (`KICKS` in attack.ts): a box kick from the base of a ruck or set piece, and by pull length a low kick (skids through), a high kick (hangs) or a long kick (territory); or a drop goal if the line goes between the posts from inside 45 m. A kick that lands in the field **bounces and stays live** (`bounce` then `loose` ball modes, `kickTwist` for the oval-ball bounce) until a player actually collects it; nothing is awarded on landing. Under a high ball both sides jump for it (`contest(..., air)`). The defence takes a moment to turn (`react`) and accelerates from a standstill; our three best-placed men chase with the pace they already have. Out on the full, 50:22 off a bounce, and dead-ball are all decided by where the ball really goes.
- **Depth and momentum (V6).** Supporters start staggered, quicker men deeper (`slotTarget`), and set off the moment the passing thumb goes down (`startRuns` / `roll`), never passing the ball. In open play they run flat out until nearly level with the ball, so depth is a starting position, not a formation they hold. Acceleration comes from the speed attribute (`acc`); there is no separate stat.
- **Tackles** are dives, and a tackler has to actually reach the runner (`REACH`), so a real gap can be run through. A sidestep makes tacklers within the step window dive at where the runner was heading, but the window is narrow, good tacklers often read it, and a second step straight after the first is read (V7): running into space is meant to be the better bet. The tackle is animated (wrap, fall, both on the ground) while **everyone else keeps moving**: the ruck is organised the instant contact is made (`setupRuck`), not when the animation ends.
- **Support and defence AI (V7).** Supporters bend their lines towards the nearest gap between defenders in their own channel (`gapY`). After a ruck, defenders caught on our side are offside (`off`) and must run back before they can tackle or intercept. On a break only the two nearest chase the runner; the rest get goal-side of their own men, so the far side stays covered. A kick is only charged down by a defender right on the kicker and in its line, and then the ball is loose, not dead.
- **Rucks are continuous.** Nearby players arrive and bind, the halfback (who shadows the ball in open play) runs to the base, or the nearest man does if the halfback would take noticeably longer, the backs line up from where they are, the defence drops back at its own pace. 80% are won with no input, 20% show a small timing bar (`ruckContest`). Play never restarts until the player plays the ball. Automatic turnovers and penalties at rucks are now very rare (`gainlineLoss` 3%, offside 1 in 125) and always shown happening.
- **Scrums** form with the real forwards, heave for a moment and resolve on their own; the feeding side nearly always wins. `Match.scrumFeed` says whose put-in it is: a scrum awarded to them is packed down on the pitch with their feed, and we can take one against the head now and then.
- **Kick-offs are kicked and chased (V8).** Ours is an ordinary passage of play started with `kickoff: true` (`koOnly`: the ball can only be kicked; there is no separate kick-off mode any more). The side crosses halfway at pace as it is struck and the ball is live like any kick: a short high one is won back about half the time, a long one is theirs. If we take it before it has gone ten metres it is their scrum on halfway (`why: 'short'`); bouncing short and rolling on is fine. Theirs comes through the air to us (`receiveKick`) and has to be caught or picked up; nothing is given. **Lineouts** are thrown with the same pull-back: three real jumpers (front, middle, back), a winger throwing in, their marker visibly covering one jumper, risk shown by the aim line's colour. Neither has a timing game, and neither resets anyone afterwards.
- **Contested rucks:** a steady bar and a fair target whose width comes from who is in the ruck (`ruckEdge`: our binders' strength against their tacklers, plus support). Dead centre (about a fifth of the zone) wins a penalty and goes straight to a kick for touch. V6's bar was too fast; V7 slowed it.
- **Penalties:** kick at goal (from inside 40 m), kick for touch, or tap. The kick for touch and the kick-off share one mechanism (`LongKick`): the dotted line is still air, the wind bends the real flight, the ball rolls on after landing, and the game never says in advance whether it will go out. The camera slides to keep the landing spot and the kicker both in view.
- **Kicks at goal are taken on the pitch** with the normal camera and the same pull-back (`PlaceKick` in match.ts). Conversions are in line with where the try was scored. The dotted line is still air; each match has a wind (`Match.wind`, mostly light, sometimes strong) that bends the real flight, more the longer the kick (`WIND_PUSH`). At a conversion their man charges from the goal line the moment the thumb touches. There is no separate goal-kick screen any more.
- **The dive** is a lunge of about a metre and a half, only from inside 3 m.
- The pitch is 50 m wide (`FW`, V8); `MID` is its middle. Never write 20 or 40 for those.
- **Chips** (a short pull upfield) go 5 to 11 m, high, and are there to be chased. On screen the three kicks are **CHIP KICK, BOMB, LONG KICK** in a fixed strip under the scoreboard (`kickStrip`), the one being aimed lit; in code they are still `low`, `high`, `long`.
- **V8 match details.** A contested ruck is announced first (`ruckIntro`: big yellow CONTESTED, taps ignored until it has gone). The moment the passing thumb goes down the play is live: the carrier jogs (`poise`) and everybody runs, nobody waits for the pass. A lineout throw longer than `LO_OVER` goes over the top to the backs as a real ball in the air (`longThrow`). At their scrum one of their men is shown feeding (`Match.feeder`). Featured players wear a small gold star. Defending wingers stand a little infield. Beyond the touchlines there is a stand, boards, benches, coaches and a touch judge (`drawStadium`), all deliberately dim. The kick for touch has a miniature of the whole pitch with the kick's line on it; it still never says whether the ball will go out.
- **Early seasons are easier.** `easeOf(career)` is 1, 0.65, 0.3 in the first three seasons and 0 after (always 0 in a World Cup); `sideFromTeam(t, morale, ease)` slows and weakens the opposition by it. There is no "Lightning Round" mode, though Rocky's V8 brief mentions one.
- **Set plays:** a starting mark for each of the nine supporters plus an optional arrow he runs along (a tenth quicker than his normal pace while on it) before returning to normal support. A mark can be a dummy runner (`Spot.recv === false`: never looked to as a receiver), one mark can be the primary receiver (`Formation.primary`: preferred when the pass could go to him), and on the training ground one can start with the ball (`Formation.ball`). Called from the small Set plays button, which only shows before the ball is played. Runners walk to their marks; they are never placed.
- **Attributes:** speed = pace; handling = pass accuracy, hard catches, holding on in the tackle; kicking = range and accuracy; strength = bumping off tacklers and tackling; stamina = pace lost late in a match.

## V9 on the pitch
- **Swipes are small again.** A swipe that is let go moves the runner 1 to 2.5 m (`CARRY`); Rocky found V8's version far too big. Sideways speed (`lateralSpeed`) is 2.1.
- **Under any kick one man goes for the ball** (ours: `chasers[0]`; theirs: `catcher`), kept unless somebody is clearly better placed; the next men hold off either side in support and only converge if it goes loose.
- **A penalty kicked for touch is a live passage of play** (`Match.startTouchKick` → `startPlay({ penKick: true, push })`): both sides on the field, the wind carries the real ball (`push`), it can be caught or bounce, and out untouched (`penLive`) is our throw (`lineoutUs` with `pen`). The old `LongKick` / `touchkick` mode is dead code now. A kick going out on the full flies the first part of its arc (`ball.cut`) so it is still in the air at the line.
- **Mauls.** A won lineout becomes a driving maul 65% of the time (`T.maulChance`, `startMaul`, state `maul`). It goes forward at a pace set by the two packs, nothing can go wrong for three seconds and then the risk of being held up climbs (`maulRisk`). Any touch plays it away (`playMaul`) and that touch carries on as a run or a pass. It can be driven over for a try.
- **Tackling and stepping.** Tacklers stay on their feet until close (`commitAt`: 1.35 m for a good one, up to 1.95 m for a poor one). The sidestep window is 3.8 m down to 1.5 m, good tacklers read it more often, and a second step within 2.2 s is usually read.
- **Ruck penalties** need the very middle of the target: the sweet spot is 10% of it for a weak pack, up to 22% for a strong one. **The conversion charger** starts on the goal line 60% of the way across towards the kicker's side.

## After V9 (same day, from Rocky's follow-up messages)
- **Training board:** players are drawn at about half size (`K`) so the shape reads. Under the board is a **time slider**: the play is run forward in the real engine against their defence with a fixed seed (`simulate()`, a frame every thirtieth of a second) and the slider scrubs through it, the board following the ball. Marks and runs are edited at time 0; anywhere else, tap a man and **Pass to him here** adds a timed pass (`Formation.passes`: `{ t, to }`, up to five, shown as marks on the slider).
- **Timed passes run by themselves** (`script`, `passTo`, `only` in attack.ts): once the play is started the ball goes to each named man at his time, never forward, and nobody else of ours takes it. The player takes over the moment he passes or kicks by hand; a tackle ends the script. In a match: call the play, touch to start it, watch.
- A kick-off or a kick for touch **cannot be run with** (`go()` refuses while `koOnly`). The fullback stands about 20 m back, commits late and reads most sidesteps. The two men on the ends of their line are their quickest. The ruck penalty spot is 5 to 12% of the target and is drawn at its true width.
- **Set plays are for a scrum or a lineout** (`Formation.from`; Scrum / Lineout switch on the board, which resets the shape). In a match the Set plays list shows scrum plays at scrums, lineout plays at lineouts, and everything at a ruck or tap. On the board a lineout play starts 10 m in from the top touchline (`LO_Y`).
- **The man with the ball can be dragged** to a different start (`Formation.start`, training and preview only; in a match the ball is wherever the set piece left it).
- **Timeline actions:** away from time 0 the side panel has **Pass** (then tap who) and **Kick** (then tap where); kicks are `Formation.kicks` (`{ t, x, y }` in metres from the ball's start, up to two) and are a chip, bomb or long kick by distance (`kickTo`).
- **Defenders bite during a called play** (`bite` in `defend()`): for five seconds each line defender goes forward at his own man, decoy or not, which is what opens the gaps. **Chips are quicker** (`KICKS.low` hang 0.82 s, lower arc).
- **The board is a real scrum or a real lineout** (Rocky: the field must look the same for both, and the men must be set up as the set piece has them, because set plays come off the back of these). The preview and Train play build the engine's own set piece (`cfg()` with `set: true`, then `releaseSet()`), so the forwards are packed or lined up and drawn but not placed, and only the **backs** are marks: six at a scrum, five at a lineout (`scrumSpots`, `lineoutSpots`, `STARTER_PLAY`). The board is the full width of the pitch; at a lineout its top edge is the touchline (`OY`, `XS`). A new play starts with one pass, halfback to first five, because a play with none is just the halfback running into their pack. Plays saved with the old nine marks are reset to the standard shape when opened. Called at a ruck with more men free than marks, the marks go to men spread evenly along the line and the rest play as normal.
- **Receive pass, Primary receiver and Starts with ball are gone from the board** (Rocky found them redundant or confusing once passes are placed by hand). The halfback starts with the ball; a run is yellow if a pass goes to that man and white if not. The engine still understands `recv`, `primary` and `ball`, but the board clears them.
- **Changes of direction on the timeline** (`Formation.turns`: `{ t, to, x, y }`, up to ten): away from time 0, tap a man and then tap open field, and from that moment he runs to that point (`turns` in attack.ts replaces his line; for the man carrying the ball it is a move across only). **Set-play kicks are always low and hard** (`KICKS.drive`), never a bomb.
- **A change of direction is drawn like a run** (Rocky disliked tap-to-place squares): with a man chosen away from time 0, drag on the field and an arrow is pulled out from where he is at that moment (`turning`, `aimTurn`, shared `arrow()`). **The chosen player's face, name and position sit in an orange box** at the top of the side panel (`chosen()`), so it is obvious who is selected.
- **Forwards and the halfback can be chosen once the slider is off 0** and given passes and new runs. They have no mark, so an action names them as `100 + their place in the side` (`OFF_MARK`, `manOf` in attack.ts, `man()` on the board). **Only the run each man is on right now is drawn**: his first until a newer one has started, and nothing once he has run it.
- **Sprint fatigue** (`gas` on every player, `burn()`, folded into `spd()`): running flat out with the ball, or chasing back in `cover`, empties a tank at a rate set by stamina (about 7 s for poor stamina, 14 s for good) and costs up to a fifth of top pace; it refills slowly when he eases off. Stamina also costs more over the match (`0.0045` in `spd()`). **The fullback** comes at full pace, takes the angle away, reads most steps and is rarely bumped off. **Their wingers** (`Def.wing`, the ends of the line, their quickest men) leave their man and run to cut the runner off as soon as the line is `broken`. **The conversion charger** runs at 8.4 m/s. **Matches are a fifth shorter** (`CLOCK_RATE` 1.25 in match.ts: the clock still counts to 80).
- **Balance after all of this (bot, weak starting squad, no early-season easing):** mid-skill about 4-14, top-skill about 11-8, 1.6 tries a match at best. Scoring is low; Rocky asked for each of these defensive changes, so it was left for him to judge on the phone. The levers if it is too hard: `tackleSuccess`, `defSpeed`, `stepWindow`, the fullback's numbers in `defend()`/`sidestep()`, `burn()`, and `easeOf`.
- **An arrow is a direction, not a distance or a speed.** Every drawn run is run flat out whatever its length, and a man who reaches the end of his arrow keeps going the same way (`heading` in attack.ts) until the play breaks down. **The man with the ball follows a run he is given** (his line steers him across) until a thumb steers instead. **A new run can be pulled straight out of a player** mid-play (`tap0` / `startTurn` on the board): a tap chooses him, a pull from him or from open field draws the run, and it overrides whatever he was doing at once.
- **Set plays mirror** (`flip` in `usePlay`, `AttackPlay.flipped`): they are drawn with the open side below the ball, and are turned over (marks, runs, passes, kicks, new runs) for a lineout on the bottom touchline or a scrum more than 6 m below the middle of the field.
- **A lineout starts with SET PLAY or THROW** when the career has at least one lineout play (`loStage` / `drawLoChoice` in matchscene.ts; not in practice scenarios). Throw is the normal aimed throw. Set play (`Match.lineoutPlay`) skips the throw: the ball is won, everybody is put straight on the chosen play's marks, and the first touch starts it. It cannot be stolen and does not become a maul.
- **Support stays behind the ball** (`crawl` in `live()`): one of ours who is ahead of it drops to a tenth of his pace until it has come past. **A called play is dropped 18 times in 100** (`SET_PLAY_DROP`, `rollFumble`: one of its own passes, picked at random, is knocked on; Rocky's words were "up 18% chance of dropping the ball in a set play", read as per play, not per pass; the board's preview turns it off with `noFumble`). **A kick at goal is seen going over**: its flight is stretched to land 10 m beyond the posts. **Bounces are livelier**, and a pass nobody reaches bounces on instead of stopping dead. **Set plays only show at their own set piece**, first phase only: scrum plays at a scrum, lineout plays at a lineout, nothing at a ruck or tap. **Their wingers stand 8 m behind their line** (`WING_DEPTH`) and only come up for a break; **their fullback holds his depth until the line is `broken`** (or the runner is within 4.5 m).
- **Aiming is not playing** (Rocky, after V9): at a ruck, scrum or lineout nothing moves when the passing thumb goes down; play starts when the ball is actually released, or when the running thumb sets off with it. `startRuns()` now only starts a called play that passes by itself. This replaces V6/V8's 'the line sets off while the ball is aimed'.

## Careers and competitions
- **Any number of careers (six slots)**, each under `trytime.career.<id>` with an index (`src/career/saves.ts`). The title screen is CONTINUE CAREER (a list of cards, each with a small, confirmed Delete) and NEW CAREER. Old single saves are moved into slots the first time the list is read.
- **Tabs: My Career, Squad, Match Centre, Fixtures & Results, Open Market.** My Career is home (team, competition, season, record, position, achievements, next match, career history) and the way in to the Training Ground and Facilities (`ClubScene`). Fixtures & Results is one page with Fixtures / Results / Standings, and standings are only ever the competition this career is in.
- **Match Centre:** KICK OFF and SIM GAME (exact labels). A Kit button switches home and away jerseys (`Career.away`); jerseys are the team's two colours in a band, hoops or plain (`kitOf`), and the opposition changes if theirs is too like ours (`matchKits`).
- **Credits come from matches** (`PAY` in career.ts): 3 for playing one, +2 for a win, +1 for a draw; a simulated match pays 1, +1 for a win; 10 for a title, 5 for finishing a season. Shown on a MATCH COMPLETE card (`EarnScene`, `Career.lastEarn`). They buy players (`signFee`: about 4 credits for a 70, 12 for an 80, 23 for a 90), a market refresh (8) and training points (3 each). The salary cap is the separate, second test.
- **Open Market:** ten players, one for each position, mostly affordable, nobody above 84 in a first season. Rows show face, name, position, OVR and price; tapping one opens his profile (all attributes, the position's key ones marked, potential, salary, who he replaces, RECRUIT). The five stored stats are Stamina, Handling, Passing, Kicking and Tackling. Pace and physical-contact scores are derived internally, with position-based weighting; tackles and breakdowns use Tackling.
New game → pick a competition:
- **Super Rugby Pacific** (11 clubs, a season then the top four) or **Northern Hemisphere** (the URC: 16 clubs, a season then the top eight). Both leagues run every season whichever you are in. Internally they are `comps.south` and `comps.north`. Every year where `year % 4 === 3` (2027...) a World Cup follows the season and club coaches get national offers. Then the off-season: ageing, retirements, contracts, job offers. Saved under `trytime.save.v1`.
- **International Rugby:** the 2027 World Cup as a stand-alone tournament (`mode: 'cup'`), 24 nations in the six pools as drawn (`WC_POOLS`), top two of each pool plus the four best thirds into a seeded last 16. Saved apart under `trytime.cup.v1` and cleared when it finishes.
- (Older notes follow; where they disagree with the V9 list above, V9 wins.)
- Squads are **12** (five forwards, seven backs, two of them centres); **ten** take the field in open play (`ORDER` in side.ts; the fullback, second from the end, is the defence's sweeper). Saves from the brief 10-player period get centres added on load. Tabs are listed above.
- **A new club career starts with a generic squad and one featured player** (a fullback, wing or first five, well above the rest; `star` on the player). Other clubs and all nations have full squads, so the first season is hard on purpose.
- **Open Market**: signing costs credits (`signFee`) and the salary must fit the **$1M cap** (`CAP` = 1000, in thousands). A signing replaces your weakest man in that position (`slotFor`), who goes back on the market. Featured players gain the odd attribute point from playing matches. All money is fictional; none of this touches real payments.
- **Training Ground** (Club tab, rebuilt in V8): five fixed plays, **Play 1 to Play 5**, across the top; no names, no Save button. Every change is written at once into the career's own save (`Career.plays`, `getPlays`/`putPlays` in plays.ts), so each career has its own five. Tap a player for his panel: Receive pass on/off, Primary receiver, Starts with ball, Clear run. Receivers' arrows are yellow, dummy runners' white. **TRAIN PLAY** runs it in the real engine with a 3, 2, 1, GO countdown and no ruck contests (`Match.noContest`), then a results card with RETRY PLAY and EDIT PLAY. Play 1 starts as a sample and is free; Plays 2 to 5 sit behind the premium flag (`trytime.premium.v1`, always on in a dev build). Nothing is sold yet and there is no payment code.

## Known gaps
- **Earlier V9 code was not tested by hand in this archive.** Things to watch on a phone: whether the smaller swipe step and 2.1 sideways speed feel right; whether mauls come too often; whether kicks for touch find touch as easily as they should; the title animation's passes; credit prices against earnings. The mid-skill bot with the weak starting squad and no easing now loses about 10-16 (defence was made harder on purpose); a first-season career is eased.
- Not built from V9: a kit designer (only home/away), acceleration and strength as separate stored attributes (deliberately omitted in favour of position-based pace and tackling), venue names, and a playable opposition attack after they catch a penalty kick (their possessions are still the text ticker).
- Nothing here has been judged by a thumb yet. Balance is tuned against a bot. After V8, with the weak starting squad and no early-season easing, the mid-skill bot is about level (16-17); a first-season career is easier than that. The opposition's simulated attack was sharpened in V7 (oppsim.ts) because rucks no longer hand them the ball. The flick threshold (`FLICK_V`) and pull-back length (`AIM_MAX`) in matchscene.ts are guesses.
- **No playable defence.** Rocky's V4 brief asked for a clearer "controlled defender"; there isn't one to make clearer. Building defence is its own project.
