# Games

Personal game development projects.

## Tiny Rugby Simulator (TRS)

A mobile-first rugby career game. Source code is in [`tiny-rugby-simulator/`](tiny-rugby-simulator/).

The title uses small white **tiny** text, oversized blocky yellow **RUGBY** text, and small white **simulator** text.

### Running locally

```bash
cd tiny-rugby-simulator
npm ci
npm run dev
```

### Validation

```bash
npm test
npm run build
```

See `TRS-REVIEW-NOTES.md` for changes and remaining tasks. This is a work-in-progress, not a tested release build.
